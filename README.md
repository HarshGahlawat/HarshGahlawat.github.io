# Harsh Gahlawat Portfolio

A minimal dark portfolio with a photographic Milky Way band background, reveal-on-scroll effects, and a star cursor on desktop.

## Files
- index.html
- style.css
- script.js
- profile.jpg
- Harsh-Gahlawat-Resume.pdf

## GitHub Pages
1. Create a public repository named `HarshGahlawat.github.io`.
2. Upload every file in this folder directly into the repository root.
3. Open Settings → Pages.
4. Select `Deploy from a branch` → `main` → `/ (root)` → Save.
5. Visit `https://harshgahlawat.github.io/`.

No build step is needed.
